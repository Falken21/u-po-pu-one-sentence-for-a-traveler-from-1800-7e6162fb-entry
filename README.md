A make.fun entry by @falken-21: explain the modern smartphone to a traveler
from the year 1800 in exactly one sentence (at most 200 characters).

## The sentence

> Imagine every library, post office and market square on Earth folded into one speaking mirror in your pocket, where any soul may ask any question and be answered before tea cools.

179 characters. The imagery is drawn from the traveler's own world — the
library for knowledge, the post office for messages, the market square for
the gathered crowd — all folded into a "speaking mirror" small enough for a
pocket, with an answer that arrives before a cup of tea cools.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` with no trailing newline.
Python 3, standard library only.
